## How to use these

Work the problems first. Then open the solution and compare — not just the
answer, but the route to it.

The worked solutions include the charts and the reasoning. You can read them
straight here on GitHub (the **read** link) or run them in Colab.

Nobody is marking these. The value is entirely in the attempt.

## What is in a problem set

1. **Brief** — what the data is and where it came from
2. **Setup** — one cell; it fetches the CSV
3. **Columns** — types and missing values
4. **Three problems**
   * **Easy — describe.** Read the data before touching a model.
   * **Intermediate — build.** Make something and measure it.
   * **Advanced — judge.** Decide what it is worth and where it fails.

## Working with AI on these

Use ChatGPT, Claude, Gemini or Colab's assistant. The skill is not typing pandas
from memory — it is asking for the right thing, reading the output critically,
and noticing when a confident answer is wrong.

Every dataset has a trap in it: a biased sample, a hindsight label, a misleading
average, a column split by capitalisation. An AI will walk straight past them.

## The data

Several sets are scraped or synthetic and carry real limitations, stated in each
notebook. They are published for teaching. Do not use them to make decisions
about actual people.
